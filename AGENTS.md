# Сайт ilya-novitsky.ru — бриф для работы с репозиторием

Читать перед любыми правками.

## Что это
Личный сайт Ильи Новицкого: маркетинг, продукт и автоматизация на уровне директора, без найма в штат.
Сайт говорит с предпринимателем на его языке: сначала ситуация и выгода клиента, «я» — только как факт опыта.

## Как устроено
- Next.js 14, статическая сборка (`output: 'export'`), хостинг GitHub Pages. Выкладка — push в `main` (`.github/workflows/deploy.yml`).
- Страницы: `src/app/<маршрут>/page.tsx`. Один блок страницы = один файл в `src/components/<страница>/`.
- Общие данные: `src/config/` — контакты и меню (`site.ts`), цены (`prices.ts`), цели Метрики (`goals.ts`), блог (`blog.ts`), переадресации со старых адресов (`redirects.ts`).
- Блог: `content/blog/*.md` (frontmatter проверяется при сборке, ошибка = сборка падает).
- Документы: `content/legal/*.md` → `/offer`, `/privacy`, `/consent`.
- Книга: исходники `content/book/*.mdx`, готовые главы `public/book/*.html` собирает `scripts/book/build_book.py` (см. шапку скрипта). Тексты книги не меняем.
- Стили: `src/styles/tokens.css` (цвета, шрифты) и `base.css`. Шрифты — Manrope и JetBrains Mono, свои файлы, без запросов к Google.
- Метрика грузится только после «Принять все» в баннере cookie (`CookieBanner.tsx`). Цели — через `data-goal` и `src/lib/analytics.ts`.

## Правила текстов
- Без внутрянки CRM: причины отказов, «дорого», выгрузки не публикуем.
- Клиентов называем только с их согласия. Выдуманных отзывов и цифр нет.
- Не говорим «тяну систему», «решения принимаю я», «держится на мне».
- AI — ускорение в опытных руках, не волшебная таблетка.

## Перед выкладкой
`npm run build` без ошибок; проверить вёрстку на 360 / 768 / 1280; ссылки и якоря; в консоли нет ошибок.
