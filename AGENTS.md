# Сайт ilya-novitsky.ru — бриф для работы с репозиторием

Читать перед любыми правками. Чертёж проекта — `docs/BLUEPRINT.md`, решения — `docs/DECISIONS.md`, поиск — `docs/SEO.md`.

## Что это
Личный сайт Ильи Новицкого: маркетинг, продукт и автоматизация на уровне директора, без найма в штат.
Сайт говорит с предпринимателем на его языке: сначала ситуация и выгода клиента, «я» — только как факт опыта.

## Где что лежит
- **Тексты — только в `content/`**, вёрстка их не содержит:
  - `content/pages/*.ts` — страницы (главная, кейсы, как мы работаем, наставничество, блог, книга, общие тексты);
  - `content/cases/*.md` — один файл = один кейс; `content/blog/*.md` — статьи; `content/legal/*.md` — документы; `content/book/` — главы книги.
  - Разметка в строках: `**жирный**`, `[текст](адрес)`, `{{без переноса}}`. Неразрывные пробелы в числах ставит `src/lib/typo.ts` сам.
- **Цены и сроки** — только `src/config/prices.ts`. Контакты, меню, реквизиты — `src/config/site.ts`. Старые адреса — `src/config/redirects.ts`.
- **Вёрстка**: `src/app/<адрес>/page.tsx` собирает блоки; один блок = один файл в `src/components/<страница>/`.
- **Стили**: `src/styles/tokens.css` (цвета, шрифты) и `base.css`. Фон блоков: белый и серый (`alt`) строго через один, 2–3 тёмных (`dark`) на страницу.
- **Метатеги и schema.org** — `src/lib/seo.ts` (`pageMeta`, разметка). Превью — `public/og/` (`npm run og`).
- **Книга**: главы `public/book/*.html` собирает `scripts/book/build_book.py`. Тексты книги не меняем.
- **Метрика** — только после «Принять все» в баннере cookie. Цели — `data-goal` и `src/lib/analytics.ts`.

## Сборка и проверки
`npm run build` → после сборки сами идут проверки (`npm run check`): ссылки и якоря, переадресации, SEO каждой страницы, вес страниц.
Упала проверка — сайт не выкладывается. Поменялся заголовок страницы — `npm run og`, потом снова `npm run build`.
Выкладка — только через main (GitHub Actions). Ветки и PR проверяет `check.yml`.

## Правила текстов
- Без внутрянки CRM: причины отказов, «дорого», выгрузки не публикуем.
- Клиентов называем только с их согласия. Выдуманных отзывов и цифр нет.
- Кейсы и отзывы агентства — прошлый опыт (до 2025): отзывы без имён, суть про результат; не-инфобизнес первым, без слова «инвест».
- Не говорим «тяну систему», «решения принимаю я», «держится на мне».
- AI — ускорение в опытных руках, не волшебная таблетка.
- Новые тексты — без тире и без точек в заголовках.
