## 1. СМЫСЛ ПРОДУКТА (позиционирование)

**NCAi — «Агентство в коробке».** Клиент покупает не услуги подрядчика и не доступ к нейросети, а **работающее агентство**: команду AI-сотрудников с ролями, доской задач, контролем расходов и ежедневным отчётом — всё в Telegram-панели.

**Одна фраза оффера:** «Купи не консультанта и не подрядчика — купи работающее агентство, распакованное под твой бизнес за несколько шагов».

**Три обещания продукта:**
1. **Предсказуемость** — фикс-подписка, понятные задачи, прозрачные отчёты.
2. **Скорость** — агентство разворачивается автоматически, первые задачи работают в первую неделю.
3. **Цена** — 4 900 ₽/мес вместо 150–250 тыс ₽ найма.

**Мантра:** «Не продаём услуги подрядчика — выдаём клиенту работающее агентство за подписку».

## 2. КАК ПРОДУКТ УСТРОЕН (детально)

### 2.1. Роли (команда агентства)
| Роль | Зона ответственности |
|---|---|
| 🎯 AI-директор (продюсер) | Разбирает задачу на подзадачи, делегирует, проверяет результат перед закрытием |
| ⚙️ Разработчик | Код, боты, интеграции |
| 📈 Маркетолог | Контент, воронки, книга |
| 🎨 Дизайнер | Вёрстка, креативы |
| 💰 Финансист | Учёт, юнит-экономика, отчёты |
| 👑 Владелец | Ставит задачи директору, принимает решения |

### 2.2. Цикл работы (главная механика)
```
Клиент пишет директору задачу
→ директор разбивает на подзадачи (≤1ч, с критерием готовности)
→ назначает роль
→ агент выполняет
→ директор проверяет результат
→ закрывает → вечером (18:00) отчёт клиенту
```
**Дисциплина:** директор не закрывает задачу, пока не сверил результат с критерием готовности. Это «проверка результата», а не просто раздача задач.

### 2.3. Фичи панели (что видит клиент)
- **Доска задач** — номер, срок, исполнитель, статус.
- **Команда** — роли, статусы (online/busy/idle), базы знаний.
- **Финансы** — вложено / остаток / потрачено (реальные деньги).
- **Контроль расходов на AI** — бюджет + kill-switch (агенты сами останавливаются на лимите).
- **Аналитика** — P&L-прогноз, рейтинг, отчёты.
- **Отчёт каждый вечер в 18:00** — что сделано, кто что делал.

### 2.4. Что под капотом (для блока «как это работает»)
- **Hermes** — open-source движок, на котором Илья сам управляет своей командой.
- **Мульти-аренда** — один продукт, у каждого клиента изолированный workspace (свои агенты, задачи, финансы; чужие данные недоступны).
- **Kill-switch** — бюджет на AI не даёт потратить больше лимита, сюрпризов в конце месяца нет.
- **Шаблоны под ниши** — бьюти / услуги / продажи / контент, каждая со своими ролями и стартовыми задачами.

### 2.5. Целевая аудитория
Малый бизнес с живой операционкой: салоны, клиники, магазины, услуги. Владелец, у которого вся работа в голове и руках, найм дорог (≈150–250 тыс ₽/мес), подрядчик — чёрный ящик.

## 3. ПРОЦЕСС РАСПАКОВКИ (детально, правильный смысл)

> **Важно:** распаковка = **автоматический процесс в боте, БЕЗ созвонов и сессий с Ильёй**. Методология остаётся — но её ведёт **бот**, а не живой созвон.

```
Кнопка «Начать распаковку» → бот @FunnelsBot
→ прогрев (3 коротких сообщения о сути продукта)
→ «Хочу своё агентство»
→ РАСПАКОВКА В БОТЕ ПО МЕТОДОЛОГИИ: бот ведёт клиента — чем занимается бизнес,
  кто в команде, кто владелец / кто операционка, какие задачи отдать в первую
  очередь. Не «анкета для галочки», а разбор реальной ситуации (АВТОМАТИЧЕСКИ,
  в боте, без созвона)
→ оплата 25 000 ₽ через Telegram Stars
→ кабинет разворачивается автоматически (по итогам распаковки в боте):
  workspace с названием бизнеса + AI-директор + команда под нишу + стартовые задачи
→ клиент ставит первую задачу → отчёт в 18:00
```

**Чего НЕТ (удалить со всех страниц):**
- ❌ созвон / сессия «60–90 минут с Ильёй»
- ❌ «внедрение Илья ведёт лично», «разовая сессия»
- ❌ «15 мест · $40 бюджета» (выдуманные числа)

**Что ОСТАЁТСЯ (суть продукта):**
- ✅ распаковка в боте по методологии (бот разбирает бизнес клиента)
- ✅ оплата Stars → кабинет разворачивается автоматически
- ✅ всё автоматически, без живого созвона

**Статус реализации (для внутреннего понимания, НЕ для сайта):**
- Готово: бот-воронка (прогрев + оффер), оплата Stars, авто-провижининг кабинета, доска, контроль расходов, отчёт 18:00.
- Доделывается: детальный опросник в боте (полная методология распаковки) — этап в работе. **Сайт описывает целевую механику** (распаковка в боте по методологии), а не урезанную текущую версию.

### Точные цифры оффера
