## 📌 Суть проекта

Три слоя одного сайта, которые работают как единая воронка:

```
ТРАФИК (блог → SEO)
      ↓
ПРОГРЕВ (книга → доверие → экспертиза)
      ↓
КОНВЕРСИЯ (главная → оффер → заявка)
```

| Слой | URL | Цель |
|------|-----|------|
| **Блог / Книга** | `/book`, `/book/[chapter]` | SEO + прогрев через экспертность |
| **Главная** | `/` | Продажа консалтинга |
| **Оффер** | `/work-with-me` | Закрытие заявки |

## 📚 КНИГА — СТРАНИЧНАЯ ВОРОНКА

### Концепция: `/book` как отдельный продукт внутри сайта

Страница `/book` — это **не просто лента постов**, а воронка чтения:

```
/book  (индекс)
  ↓ читатель выбирает интересную главу
/book/[slug]  (пост)
  ↓ читает, получает ценность
  ↓ Key Takeaway — инсайт
  ↓ ChapterCTA — следующая глава ИЛИ оффер
  ↓ (если прочитал 3+ главы) → попадает в ремаркетинг
/work-with-me  (оффер)
```

### Индексная страница `/book`

Структура страницы-индекса:
1. **Hero** — название «Архитектор Систем», подзаголовок, прогресс (6 глав, 30 подглав)
2. **Глава-карточки** × 6 — каждая раскрывается со списком подглав
3. **Sticky sidebar** (десктоп) — оглавление с прогресс-баром чтения
4. **CTA-полоса** в середине — «Хочешь внедрить? → Консалтинг»

export function getAllSubchapters(): (Subchapter & { chapterId: number; chapterTitle: string; chapterColor: ChapterColor })[] {
  return chapters.flatMap(ch =>
    ch.subchapters.map(sub => ({
      ...sub,
      chapterId: ch.id,
      chapterTitle: ch.title,
      chapterColor: ch.color,
    }))
  );
}

export function getSubchapterBySlug(slug: string) {
  for (const chapter of chapters) {
    const sub = chapter.subchapters.find(s => s.slug === slug);
    if (sub) return { subchapter: sub, chapter };
  }
  return null;
}

export function getChapterBySlug(slug: string) {
  return chapters.find(ch => ch.slug === slug) ?? null;
}

export const totalSubchapters = chapters.reduce((acc, ch) => acc + ch.subchapters.length, 0);

### СЕГМЕНТ A — «Действующий предприниматель в тупике»
**Возраст:** 28–42 года  
**Выручка:** 3–30М/год  
**Ситуация:** Бизнес работает, но не системно. Всё держится на нём лично.

Боли:
- Запускает продукты — не взлетают
- Нанимает маркетологов — «не то»
- Трафик есть, продаж нет
- Устал объяснять задачи подрядчикам
- Хочет уйти из операционки, но не знает как

Что ищет в консалтинге:
- Конкретный результат, не «стратегию»
- Человека, который сделает, а не расскажет
- Прозрачность процесса
- Систему, которая работает без него

**Триггер покупки:** Очередной провальный запуск / уход ключевого сотрудника / «всё, хватит»

### СЕГМЕНТ B — «Эксперт, который хочет упаковать знания»
**Возраст:** 30–50 лет  
**Ситуация:** Глубокая экспертиза, слабая упаковка

Боли:
- «Все говорят что я крутой специалист, но клиентов мало»
- Работает по сарафану — нет предсказуемого потока
- Пробовал агентства — дорого и непонятно
- Хочет курс/продукт, но не знает с чего начать
- Сайт есть, заявок нет

Что ищет:
- Перевести экспертизу в деньги
- Понять, как это работает (не просто «сделайте»)
- Сохранить свой голос и стиль

**Триггер покупки:** Видит похожего эксперта с системой / читает книгу / попадает в блог

# Пять когнитивных ловушек, которые ломают воронки ещё на старте

Воронка ломается не там, где вы думаете.

Большинство предпринимателей ищут проблему в оффере, цене или трафике. Но 80% потерь происходит раньше — до того, как человек прочитал хоть одно слово. Мозг уже принял решение.

За 0.3 секунды.

---

## Почему мозг решает раньше сознания

Наш мозг обрабатывает входящую информацию в два потока. Первый — быстрый, автоматический, инстинктивный (Система 1 по Канеману). Второй — медленный, логический, энергозатратный (Система 2).

Маркетинг обращается к Системе 2. Мозг отвечает через Систему 1.

Это и есть корневая ошибка большинства воронок.

---

## Ловушка 1: Когнитивная перегрузка

Когда на странице слишком много информации, мозг делает единственное рациональное — закрывает вкладку. Это не лень пользователя. Это энергосбережение нервной системы.

**Симптом в воронке:** высокий bounce rate на лендинге при хорошем трафике.

**Решение:** одна страница — одна идея. Одно действие. Никакого «а ещё мы можем».

---

## Ловушка 2: Эффект якоря

Первая цифра, которую видит пользователь, становится якорем для всех последующих оценок. Если вы показываете цену первой — всё, что идёт после, оценивается через неё.

**Симптом:** люди уходят после блока с ценой, не дочитав до ценности.

**Решение:** сначала ценность в деньгах или результатах, потом — ваша цена.

---

## Ловушка 3: Паралич выбора

Три тарифа, пять кнопок, шесть вариантов — и человек не выбирает ничего. Джем Айенгара: при 24 вариантах покупает 3% людей, при 6 — 30%.

**Симптом:** низкая конверсия при большом количестве опций.

**Решение:** максимум 3 варианта. Один — явно рекомендованный.

---

## Ловушка 4: Эффект Зейгарник

Незавершённые действия занимают больше когнитивного ресурса, чем завершённые. Если ваша воронка не создаёт незавершённости — она не создаёт намерения вернуться.

**Симптом:** люди заходят, смотрят, уходят и не возвращаются.

**Решение:** прогресс-бары, разбивка на шаги, «вы на 60% пути к результату».

---

## Ловушка 5: Предвзятость подтверждения

Мозг ищет доказательства того, во что уже верит. Если ваш первый экран не совпадает с убеждением клиента о его проблеме — он решит, что это «не про него».

**Симптом:** хороший трафик, нулевое вовлечение.

**Решение:** первый экран должен называть боль словами самого клиента — не вашими.

---

</KeyTakeaway>

# Нейрокопирайтинг: как текст запускает предсказуемые реакции в голове читателя

Слова — это не информация.

Слова — это триггеры. Правильная последовательность слов запускает нейронные цепи так же предсказуемо, как код запускает программу.

Это не метафора. Это нейробиология.

---

## Как мозг читает текст

Мозг не читает слева направо линейно. Он сканирует, ищет паттерны и принимает решение «читать или нет» задолго до того, как вы осознанно обработали первое предложение.

Три секунды на первый абзац. Потом — либо вовлечение, либо закрытая вкладка.

---

## Принцип 1: Разрыв любопытства

Мозг физически не может оставить незакрытый информационный пробел. Если вы создаёте вопрос — он требует ответа. Если обещаете раскрыть что-то — читатель дочитает.

**Как применять:** начинайте абзацы с вопроса или незавершённого утверждения. «Вот почему 90% воронок ломаются в одном месте...»

---

## Принцип 2: Конкретность активирует сенсорные зоны

«Хорошие результаты» — ничего не активирует. «340% рост заявок за 6 недель» — активирует зоны визуализации и вознаграждения.

Мозг реагирует на конкретику как на реальный опыт — выделяет дофамин в предвкушении.

**Правило:** каждое утверждение — с числом, именем, сроком или местом.

---

## Принцип 3: Ритм управляет вниманием

Длинное предложение создаёт напряжение. Короткое — разряжает.

Чередование длины управляет эмоциональной дугой читателя так же, как музыкальный ритм управляет настроением.

Попробуйте прочитать этот абзац вслух. Слышите?

---

## Принцип 4: Зеркальные нейроны и «ты»

Когда текст обращается «ты» и описывает конкретную ситуацию — зеркальные нейроны читателя буквально симулируют этот опыт. Читатель не читает про кого-то. Он проживает это сам.

**Как применять:** «Ты запускаешь рекламу. Трафик идёт. Заявок нет. Ты смотришь в аналитику и не понимаешь что не так.»

---

## Принцип 5: Социальное доказательство снижает страх

Миндалевидное тело — центр страха — всегда активно при принятии решений. Социальное доказательство («340 предпринимателей уже...») буквально снижает активацию страхового центра.

Это не убеждение. Это физиология.

---

## Структура нейрокопирайтинга

```
1. Боль (зеркало ситуации читателя)
2. Разрыв любопытства (почему так происходит?)
3. Механизм (как это работает на самом деле)
4. Доказательство (конкретика, не обещания)
5. Действие (одно, чёткое, без выбора)
```

</KeyTakeaway>

# Лид-магнит: как создать бесплатный продукт, который клиент забирает сам

Лид-магнит, который нужно «продавать» — провальный лид-магнит.

Если вы объясняете почему его стоит скачать — он уже проиграл. Правильный лид-магнит создаёт ощущение «это именно то, что мне нужно прямо сейчас». Без уговоров.

---

## Почему большинство лид-магнитов не работают

Три причины:

**1. Слишком широкая тема.** «Гайд по маркетингу» — никому не нужен. «Чеклист из 7 шагов для первой воронки за выходные» — уже интереснее.

**2. Ценность внутри, а не снаружи.** Название должно продавать содержимое. Большинство называют лид-магниты так, что непонятно что внутри.

**3. Несоответствие аудитории.** Лид-магнит для всех — для никого. Он должен отсекать «не тех» так же активно, как привлекать «своих».

---

## Формула правильного лид-магнита

```
[Конкретный результат] + [Для кого] + [За какое время/усилие]
```

Примеры:
- ❌ «Руководство по продажам»
- ✅ «5 скриптов, которые закрывают 80% возражений на созвоне — для экспертов»

- ❌ «Книга о маркетинге»
- ✅ «Чеклист аудита воронки: найди где теряются деньги за 30 минут»

---

## Типы лид-магнитов и их конверсия

| Тип | Средняя конверсия | Когда работает |
|-----|-----------------|----------------|
| Чеклист | 35–50% | Когда есть конкретная задача |
| Мини-курс (3–5 писем) | 20–35% | Для прогрева сложного продукта |
| Шаблон/Фреймворк | 30–45% | B2B, экспертная аудитория |
| Калькулятор/Тест | 40–60% | Когда есть переменные для расчёта |
| PDF-гайд | 15–25% | Работает если тема очень специфична |

---

## Принцип взаимности

Роберт Чалдини описал это ещё в 1984. Мозг воспринимает бесплатный подарок как долг. Получив реально ценный лид-магнит, человек чувствует психологическое обязательство ответить взаимностью.

Это не манипуляция. Это встроенный социальный механизм. Но он работает только если лид-магнит действительно ценный — а не «сборник советов из интернета».

---

## Доставка лид-магнита

Технически лид-магнит — это не файл. Это точка входа в цепочку касаний.

После получения: письмо 1 → доставка + первое касание. Письмо 2 (день 2) → дополнительная ценность. Письмо 3 (день 4) → история + оффер.

Лид-магнит без цепочки — это просто раздача файлов.

# Визуальные стимулы: как один образ останавливает автоматический скроллинг

13 миллисекунд.

Именно столько нужно мозгу чтобы обработать изображение. У вашего визуала есть ровно этот промежуток — сказать «стоп» или получить скролл мимо.

---

## Физиология скроллинга

Скроллинг — это автоматическое поведение. Лента социальной сети — это дофаминовый конвейер. Мозг в этом режиме работает как радар: ищет аномалии, отклонения от паттерна.

Ваша задача — стать аномалией.

Не красивой. Не громкой. Именно неожиданной для конкретного контекста ленты.

---

## 6 визуальных триггеров, которые работают всегда

**1. Лицо, смотрящее прямо в камеру**
Эволюционный механизм — прямой взгляд означает угрозу или важный контакт. Мозг не может его игнорировать.

**2. Незавершённый объект или «сломанный» паттерн**
Гештальт-принцип завершения. Мозг физически достраивает незаконченное — и для этого останавливается.

**3. Контрастное соотношение**
Не просто яркие цвета — именно резкий контраст между элементами. Белое на чёрном работает лучше, чем красивый градиент.

**4. Текст на изображении (не в подписи)**
Наш мозг приоритизирует текст в визуальном поле — это языковая доминанта коры.

**5. Движение (даже имитация)**
Диагональные линии, стрелки, динамичные позы — мозг читает их как движение и переключает внимание.

**6. Несоответствие контекста**
Котёнок в деловом костюме. Инструмент не там где ожидается. Нарушение ожиданий = принудительное внимание.

---

## Стоп-кадр vs Остановка

Разница критическая. Стоп-кадр — человек остановился. Остановка — человек начал читать.

Визуал отвечает за первое. Первая строка текста — за второе. Нельзя решить обе задачи одним инструментом.

---

## Проверка визуала: тест «3 секунды»

Покажите изображение человеку на 3 секунды. Закройте. Спросите: «О чём это?»

Если он не может ответить — визуал провален. Не потому что некрасивый. Потому что непонятный.

---

Визуал — это не украшение контента. Это привратник. Его единственная задача — остановить автоматическое движение пальца. Всё остальное делает текст. Не путайте их функции.
</KeyTakeaway>

# Продуктовая матрица: как выстроить линейку так, чтобы каждый продукт вёл к следующему

Один продукт — это лотерея. Линейка продуктов — это система.

Когда продуктов несколько и между ними есть логика — каждая продажа автоматически создаёт спрос на следующую. Это не случайность. Это архитектура.

---

## Почему один продукт — это ловушка

Если у вас один продукт — вы постоянно ищете новых клиентов. Стоимость привлечения растёт. Нет повторных покупок. Нет лояльности. Бизнес работает как решето.

Матрица решает это принципиально иначе: каждый клиент — это путешествие по лестнице ценности. Продал первую ступень — уже продал путь к следующей.

---

## Структура продуктовой матрицы

```
ТРИПВАЕР (низкий барьер входа)
  ↓ ценность доказана, доверие получено
ОСНОВНОЙ ПРОДУКТ (ключевая трансформация)
  ↓ результат получен, хочется большего
ФЛАГМАН (максимальная трансформация)
  ↓ стал фанатом, нужна поддержка
RETENTION (подписка / сообщество / сопровождение)
```

---

## Логика каждого уровня

**Трипваер:** стоимость ниже психологического барьера. Задача — не заработать, а превратить посетителя в покупателя. Статус «покупал» кардинально меняет последующее поведение.

**Основной продукт:** здесь живёт основная маржа. Он должен давать конкретный измеримый результат. Не «знания» — а изменение.

**Флагман:** для тех, кто хочет максимум. Высокая цена оправдана персонализацией, доступом к вам лично или гарантией результата.

**Retention:** регулярный доход. Подписка, мастер-группа, обновления. Удерживает клиентов в экосистеме.

---

## Как связать продукты между собой

Каждый продукт должен естественно открывать следующую потребность.

Пример: клиент купил чеклист аудита воронки → понял что воронки нет → купил курс по воронкам → сделал сам, но хочет проверки → купил консалтинг.

Это не апселл. Это логика трансформации.

---

<KeyTakeaway>
Продуктовая матрица — не каталог. Это маршрут трансформации клиента, на каждой остановке которого он получает ценность и видит следующий шаг. Постройте маршрут — и продажи станут следствием.
</KeyTakeaway>
