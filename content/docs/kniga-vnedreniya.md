## ЧАСТЬ I. ПОДГОТОВКА

### Глава 1. Что вы получаете: система NCAi за 30 секунд

NCAi — это **AI-агентство из 15 сотрудников**, которое работает внутри вашего бизнеса. Вы получаете:

- **6 отделов**: Управление, Разработка, Маркетинг, Контент, Финансы, Аналитика
- **15 специалистов**: директор, техлид, разработчики, маркетолог, SMM, копирайтер, дизайнер, редактор, книжный райтер, архивариус, финансист, аналитик
- **Единый пульт управления**: задачи, отчёты, финансы, команда — в одном интерфейсе
- **Автоматизация**: утренний брифинг в 10:00, вечерний отчёт в 18:00
- **Финансовый контроль**: расходы по дням/месяцам, ЗП сотрудников, юнит-экономика

**Как это выглядит для бизнеса:**

```
Вы (владелец) → NCAi Система → 15 сотрудников → Результат
     │              │                 │              │
  ставите       пульт управл.      выполняют      отчёты,
  задачу       задачи, финансы     задачи         метрики
```

## ЧАСТЬ II. УСТАНОВКА

### Глава 4. Подключение системы: пошагово

**Шаг 1. Получите доступ**
- Откройте ссылку, которую вам дал специалист NCAi
- Войдите через Telegram (кнопка «Войти через Telegram»)

**Шаг 2. Пройдите онбординг**
- Система проведёт вас по первым шагам
- Создаст ваш профиль владельца

**Шаг 3. Проверьте работу**
- Откройте вкладку «Команда» — вы увидите 15 сотрудников
- Откройте «Финансы» — увидите реальный баланс

### Глава 5. Создание аккаунтов и ролей

NCAi работает по модели «Владелец → Оператор → Сотрудники»:

| Роль | Что видит | Что может |
|------|-----------|-----------|
| **Владелец** | Всё | Ставить задачи, смотреть финансы, управлять |
| **Оператор** | Задачи, отчёты | Ставить задачи, следить за выполнением |
| **Сотрудники** | Свои задачи | Выполнять, отчитываться |

### Глава 6. Настройка отделов и сотрудников

У каждого отдела — свои специалисты:

- **Разработка**: техлид, бэкенд, фронтенд
- **Маркетинг**: Head, маркетолог, SMM, копирайтер, дизайнер
- **Контент**: редактор, книжный райтер, архивариус
- **Финансы**: финансист, аналитик

Каждый сотрудник имеет: роль, навыки, модель (рутина/сложное), стандарт работы.

## ЧАСТЬ III. НАСТРОЙКА ПОД БИЗНЕС

### Глава 7. Загрузка ваших задач и проектов

**Как ставить задачу:**
1. Откройте вкладку «Проекты»
2. Нажмите «Добавить задачу»
3. Опишите: что сделать, срок, критерий готовности
4. Выберите исполнителя (или «распредели сам»)
5. Директор распределит по отделам

**Пример хорошей задачи:**
> «Напиши пост для Telegram-канала про нашу услугу X, 500-700 знаков, с призывом записаться. Срок: завтра 18:00»

### Глава 8. Настройка воронок и контента

Система работает по методологии «Нейро-Воронка»:
- **Боль → Решение → Оффер** — структура каждого касания
- **Открытые петли** — удерживают внимание
- **Соцдоказательство** — цифры, кейсы
- **Конкретные CTA** — что делать дальше

### Глава 9. Интеграции: Telegram, сайт, оплата

- **Telegram-бот** — управление системой из чата
- **Сайт** — публикация контента (или мы создадим)
- **Оплата** — приём подписок/платежей

## ЧАСТЬ IV. ЗАПУСК И ОБУЧЕНИЕ

### Глава 10. Обучение оператора: урок 1-7

**Урок 1. Первый вход** — как войти, что где находится
**Урок 2. Постановка задач** — как описать задачу правильно
**Урок 3. Делегирование** — как распределить по сотрудникам
**Урок 4. Отчёты** — как читать отчёты сотрудников
**Урок 5. Финансы** — как следить за расходами
**Урок 6. Контроль качества** — как проверять результат
**Урок 7. Ежедневный ритм** — брифинг 10:00, отчёт 18:00

### Глава 11. Запуск первой недели работы

**День 1-2:** Подключение, знакомство с интерфейсом
**День 3-4:** Постановка первых задач, обучение оператора
**День 5-7:** Полный цикл: задача → выполнение → отчёт → контроль

### Глава 12. Контроль: отчёты, финансы, качество

**Ежедневно:**
- Утренний брифинг в 10:00 — план дня
- Вечерний отчёт в 18:00 — итоги

**Финансы:**
- Расходы по дням/месяцам
- ЗП сотрудников
- Юнит-экономика

**Качество:**
- Кодекс (штрафы L1-L4)
- Проверка по ТЗ

## Приложение: Глоссарий

- **Агент/субагент** — AI-сотрудник
- **Директор** — продюсер, распределяет задачи
- **Делегирование** — передача задачи сотруднику
- **Юнит-экономика** — доход/расход/маржа
- **Система Петрова** — метод управления: менеджер → специалист
- **Нейро-Воронка** — методология продаж (боль → решение → оффер)
