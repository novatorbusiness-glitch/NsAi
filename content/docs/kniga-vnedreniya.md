# ЧАСТЬ I. ЗНАКОМСТВО С СИСТЕМОЙ

## 1. Что такое NCAi и зачем он бизнесу

NCAi — это **искусственное агентство**, которое работает внутри вашего бизнеса. Это не «ещё один сервис» и не «чат-бот». Это полноценный штат из 15 цифровых сотрудников, которые делают реальную работу: пишут тексты, делают сайты, настраивают рекламу, считают финансы, ведут проекты.

**Почему это важно для бизнеса:**

- Вам не нужно нанимать 15 человек (это 500 000+ ₽ в месяц зарплат)
- Вам не нужно искать, собеседовать, обучать, увольнять
- Сотрудники не болеют, не уходят в отпуск, не «выгорают»
- Они работают 24/7 и отчитываются каждый день
- Всё управляется из одного «пульта» — как пульт от телевизора

**Простыми словами:** вы получаете целую компанию, которая делает работу за вас, а вы только ставите задачи и смотрите результаты.

## 2. Как это работает: общая схема

```
┌─────────────────────────────────────────────────────┐
│                   ВЫ (владелец)                      │
│              ставите задачу, смотрите результат       │
└──────────────────────┬──────────────────────────────┘
                       │
              ┌────────▼────────┐
              │   NCAi Система   │  ← пульт управления
              │ (приложение,    │
              │  бот, панель)    │
              └────────┬────────┘
                       │
        ┌──────────────┼──────────────┐
        ▼              ▼              ▼
   ┌─────────┐   ┌─────────┐   ┌─────────┐
   │ Директор │──▶│ Отделы  │──▶│ 15      │
   │ продюсер │   │ 6 шт    │   │ сотрудн.│
   └─────────┘   └─────────┘   └─────────┘
        │              │              │
        └──────────────┴──────────────┘
                       │
              ┌────────▼────────┐
              │    РЕЗУЛЬТАТ     │
              │  задачи, отчёты, │
              │  финансы, контент│
              └─────────────────┘
```

**Как происходит работа:**

1. Вы ставите задачу: «Напиши пост про нашу услугу»
2. Директор-продюсер понимает, кому её отдать (копирайтеру)
3. Копирайтер выполняет, отчитывается
4. Вы видите результат в отчёте

## 3. Что вы получаете: 15 сотрудников и 6 отделов

### Управление
- **Директор (продюсер)** — главный. Распределяет задачи, контролирует, собирает отчёты

### Разработка (3 человека)
- **Главный разработчик (техлид)** — архитектура, код, деплой
- **Разработчик (бэкенд)** — боты, API, интеграции
- **Разработчик (фронтенд)** — сайты, интерфейсы

### Маркетинг (5 человек)
- **Руководитель маркетинга** — стратегия, распределение
- **Маркетолог** — трафик, воронки, реклама
- **SMM-продвижение** — соцсети, публикации
- **Копирайтер** — тексты, лид-магниты
- **Дизайнер** — визуал, креативы, страницы

### Контент и книга (3 человека)
- **Главный редактор** — контроль качества текстов
- **Книжный райтер** — книги, главы
- **Архивариус** — база знаний, файлы

### Финансы (2 человека)
- **Финансист** — юнит-экономика, бюджеты
- **Аналитик** — данные, исследования

## 4. Сколько это стоит и как окупается

**Что вы платите:**
- Подписка NCAi (внедрение + поддержка)
- Реальные расходы на «мозги» (токены) — обычно $20-50 в месяц

**Что вы экономите:**
- 15 живых сотрудников = 400 000 - 700 000 ₽/мес зарплат
- Время на найм, обучение, контроль

**Пример окупаемости:**
- Затраты: 50 000 ₽/мес (внедрение + токены)
- Экономия: 400 000 ₽/мес (штат)
- **Окупаемость: мгновенная** — вы экономите больше, чем платите

## 11. Подключение облачной базы данных

**Что такое Supabase:**
Это облачная база данных (PostgreSQL) + авторизация + хранилище. Все данные системы (сотрудники, задачи, финансы) хранятся там.

**Как подключить:**
1. Создайте аккаунт на supabase.com (бесплатно)
2. Создайте новый проект (дайте имя, например «my-company-ncai»)
3. Получите два ключа: `URL` и `API Key` (в настройках проекта → API)
4. Создайте таблицы (мы дадим SQL-скрипт, или создадим сами)
5. Вставьте ключи в файл настроек `.env`:

```
SUPABASE_URL=https://ваш-проект.supabase.co
SUPABASE_ANON_KEY=ваш-публичный-ключ
SUPABASE_SERVICE_KEY=ваш-секретный-ключ
```

**Важно про безопасность:**
- `ANON_KEY` — публичный, можно показывать
- `SERVICE_KEY` — секретный, НИКОГДА не показывайте (даёт полный доступ)

## 12. Настройка Telegram-бота

**Зачем бот:** управлять системой из Telegram — ставить задачи, получать отчёты, нажимать кнопки.

**Как создать бота:**
1. В Telegram найдите `@BotFather`
2. Напишите `/newbot`
3. Дайте имя (например «Моя компания AI») и username (например `my_company_ai_bot`)
4. BotFather даст **токен** — это ключ доступа

**Как подключить к системе:**
1. Возьмите токен (вида `123456:ABC-DEF...`)
2. Вставьте в `.env`:
```
TELEGRAM_BOT_TOKEN=ваш-токен
```
3. Перезапустите систему

**Как настроить кнопку «Открыть»:**
- В Telegram есть «меню-кнопка» внизу чата — можно прикрепить ссылку на приложение
- Это делается одной командой (мы настроим)

## 13. Настройка оплаты (подписки/платежи)

**Вариант 3: Простой (для старта)**

- Работает, пока не наберёте клиентов

# ЧАСТЬ IV. НАСТРОЙКА ПОД ВАШ БИЗНЕС

## 15. Создание аккаунтов и ролей

NCAi работает по принципу «Владелец → Оператор → Сотрудники»:

| Роль | Что видит | Что может |
|------|-----------|-----------|
| **Владелец** | Всё | Ставить задачи, финансы, управление |
| **Оператор** | Задачи, отчёты | Ставить задачи, следить за выполнением |
| **Сотрудники** | Свои задачи | Выполнять, отчитываться |

**Как создать роли:**
1. Вкладка «Команда»
2. «Добавить пользователя»
3. Выберите роль (владелец/оператор)
4. Укажите Telegram-аккаунт

## 16. Настройка отделов и сотрудников

Каждый отдел уже настроен по умолчанию. Вы можете:

**Настроить отдел:**
- Изменить название
- Добавить/убрать сотрудников
- Задать бюджет

**Настроить сотрудника:**
- Роль (бэкенд/фронтенд и т.д.)
- Навыки (что умеет)
- Модель (рутина/сложное — что ему поручать)

**Важно:** не меняйте «мозги» без необходимости — маршрутизация уже оптимальна (рутина на бесплатной модели, сложное на мощной).

## 17. Загрузка ваших проектов и задач

**Как создать проект:**
1. Вкладка «Проекты»
2. «Новый проект»
3. Название, описание, цвет

**Как добавить задачу:**
1. Откройте проект
2. «Добавить задачу»
3. Опишите: **что сделать, срок, критерий готовности**

**Правило хорошей задачи (ТЗ):**
```
Задача: Написать пост для Telegram о запуске скидки
Требования:
- Объём 500-700 знаков
- Тон: тёплый, человеческий
- Обязательно: цифра скидки, срок акции, кнопка/призыв
- Срок: завтра к 18:00
```

**Примеры задач по отделам:**
- **Разработка:** «Сделай страницу "О нас" на сайте», «Почини кнопку отправки формы»
- **Маркетинг:** «Напиши 5 постов на неделю», «Настрой воронку для новой услуги»
- **Контент:** «Напиши статью "Как выбрать услугу"», «Сделай обложку для поста»
- **Финансы:** «Посчитай юнит-экономику за месяц», «Сделай прогноз на квартал»

## 18. Настройка воронок и контента

**Что такое воронка:** путь клиента от «узнал» до «купил».

**Структура (по книге «Нейро-Воронка»):**
1. **Привлечение** — клиент узнаёт о вас (реклама, соцсети)
2. **Интерес** — клиент заинтересовался (контент, прогревы)
3. **Доверие** — клиент верит (кейсы, отзывы)
4. **Решение** — клиент готов купить (оффер, скидка)
5. **Оплата** — клиент платит

**Что настроить:**
- [ ] Список услуг с ценами
- [ ] Тексты для каждого этапа
- [ ] Кнопки/призывы («Записаться», «Купить»)
- [ ] Автоматические сообщения (прогрев, дожимы)

## 19. Интеграции: сайт, бот, аналитика

**Сайт:**
- Подключается через GitHub Pages или Vercel
- Сотрудники публикуют контент на сайт

**Бот:**
- Управление из Telegram
- Кнопка «Открыть» ведёт в приложение

**Аналитика:**
- Реальные расходы по дням/месяцам
- Кто сколько работает
- Окупаемость

## 21. Урок 2: Как ставить задачи

**Правило:** задача = **что сделать + срок + как проверить**.

**Плохо:** «Занимайся маркетингом»
**Хорошо:** «Напиши 3 поста для Telegram на этой неделе (пн/ср/пт), по 500-700 знаков, про нашу услугу X. К пятнице покажи тексты.»

**Совет:** одну большую задачу лучше разбить на 3-5 маленьких — так легче контролировать.

## 22. Урок 3: Как делегировать сотрудникам

**Правило:** делегировать = **выбрать правильного сотрудника**.

| Задача | Кому отдать |
|--------|-------------|
| Текст, пост, статья | Копирайтер |
| Дизайн, обложка, креатив | Дизайнер |
| Сайт, код, бот | Разработчик |
| Реклама, воронка | Маркетолог |
| Финансы, экономика | Финансист |
| Анализ, данные | Аналитик |

**Пошагово:**
1. Откройте задачу
2. В списке «Исполнитель» выберите сотрудника
3. Нажмите «Делегировать»
4. Система запустит сотрудника, он выполнит и отчитается

**Совет:** если не знаете, кому отдать — поставьте «Директору», он распределит сам.

## 23. Урок 4: Как читать отчёты

**Что в отчёте:**
- Задача (что делал)
- Номер (для отслеживания)
- Время (сколько заняло)
- Расход (сколько денег потрачено)
- Статус (готово/в работе/ошибка)

**Как читать:**
- Вкладка «Отчёты»
- Выберите период (сегодня/7 дней/30 дней)
- Смотрите по сотрудникам

**Признаки хорошего результата:**
- Задача выполнена по ТЗ
- Отчёт конкретный (что сделано, как проверить)
- Расход адекватный

**Признаки проблем:**
- Статус «ошибка»
- Отчёт «сделано» без деталей
- Расход высокий без объяснения

## 24. Урок 5: Как следить за финансами

**Что смотреть:**
- **Баланс** — сколько осталось (план + пополнения)
- **Расходы по дням** — сколько потрачено
- **Расходы по месяцам** — динамика
- **Расход на сотрудника** — кто сколько жжёт
- **Юнит-экономика** — стоимость одной задачи

**Как читать:**
- Вкладка «Финансы»
- Смотрите: сегодня/неделя/месяц
- Норма: расход на задачу небольшой, баланс не падает резко

**Когда пополнять:**
- Баланс < 2-3 дней работы → пополнить
- Обычно $20-50 хватает на месяц

## 25. Урок 6: Как проверять качество

**Правило:** не принимайте результат «как есть» — проверяйте по ТЗ.

**Чек-лист проверки:**
- [ ] Задача выполнена полностью (все пункты ТЗ)
- [ ] Текст без ошибок, читается
- [ ] Код/сайт работает (если применимо)
- [ ] Нет воды, есть конкретика
- [ ] Расход адекватный

**Если плохо:**
- Верните на доработку («не по ТЗ, переделай»)
- Директор проконтролирует

## 26. Урок 7: Ежедневный ритм работы

**Утро (10:00):**
- Приходит утренний брифинг — план дня
- Проверьте: какие задачи в работе
- Поставьте новые

**День (10:00-18:00):**
- Сотрудники работают
- Вы можете заходить, смотреть прогресс

**Вечер (18:00):**
- Приходит вечерний отчёт — итоги дня
- Проверьте: что сделано, что осталось
- Поставьте задачи на завтра

**Совет:** 15 минут утром + 15 минут вечером достаточно для управления всей системой.

```bash

pip install -r requirements.txt  # backend

# 3. Настроить .env
cp .env.example .env
```

## 34. Безопасность и резервное копирование

**Безопасность:**
- Ключи хранятся в `.env` (не в коде!)
- SERVICE_KEY никогда не публикуется
- Пароли не хранятся (вход через Telegram)

**Резервное копирование:**
- Данные в Supabase (облако) — резервируются автоматически
- Локальные файлы — копируйте папку `.run` периодически
- Код в GitHub — всегда есть история

## 35. Устранение неполадок

**«Сотрудник не отвечает»**
- Проверьте баланс (кончились токены)
- Проверьте интернет
- Перезапустите задачу

**«Ошибка RLS / нет доступа»**
- Проверьте ключи Supabase
- Проверьте, что мастера созданы в базе
- Напишите в поддержку

**«Расходы не сходятся»**
- Проверьте вкладку «Финансы» — там единый источник истины
- Обновите страницу

**«Сайт не открывается»**
- Проверьте GitHub Pages (Settings → Pages)
- Перезапустите деплой (Actions)

# ПРИЛОЖЕНИЕ A. ГЛОССАРИЙ

- **Агент / субагент** — AI-сотрудник
- **Директор / продюсер** — главный, распределяет задачи
- **Делегирование** — передача задачи сотруднику
- **ТЗ (техзадание)** — описание задачи: что сделать + как проверить
- **Юнит-экономика** — доход/расход/маржа на единицу (задачу/клиента)
- **RLS** — система ограничения доступа к данным в базе
- **Токены** — «горючее» для AI (расходуются при работе)
- **Система Петрова** — метод управления: менеджер → специалист
- **Нейро-Воронка** — методология продаж (боль → решение → оффер)
- **Онбординг** — знакомство с системой при первом входе
- **Воронка** — путь клиента от «узнал» до «купил»
