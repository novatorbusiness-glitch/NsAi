# ilya-novitsky.ru

Личный сайт Ильи Новицкого, архитектора продукта и продаж: аудит, чертёж системы, ведение.
Next.js (статическая сборка) → GitHub Pages. Выкладка — push в `main`.

- **С чего начать:** `AGENTS.md` — где что лежит и правила.
- **Чертёж до каждого файла:** `docs/BLUEPRINT.md` · **решения:** `docs/DECISIONS.md` · **поиск:** `docs/SEO.md`.
- **Тексты** — `content/`, **цены** — `src/config/prices.ts`.

```bash
npm ci
npm run build   # сборка + проверки: ссылки, переадресации, SEO, вес
npm run og      # перерисовать превью, если поменялся заголовок
```
